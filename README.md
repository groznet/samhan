# Samhan — сайт компании

Многостраничный статический сайт: HTML + TailwindCSS (CDN) + Alpine.js. Без сборки — просто открыть в браузере или разместить на GitHub Pages.

## Структура

```
index.html            Главная
about/index.html       О нас
services/index.html    Услуги (5 разделов + FAQ)
projects/index.html    Проекты (фильтр по категориям)
contact/index.html     Контакты (форма + карта)
privacy/index.html     Политика конфиденциальности
assets/css/main.css     Общие стили, дизайн-токены, "ламельный" мотив
assets/js/main.js       Скролл хедера, плавное появление блоков
assets/images/visuals/  Иконки и декоративные SVG
components/             Пояснительные заметки о переиспользуемой разметке
```

## Дизайн

Цвета и шрифты — по брифу (Montserrat/Inter, #1F2937 · #9CA3AF · #C59D5F · #F9FAFB · #111827). Сквозной визуальный мотив — «ламель» жалюзи: тонкие полосы-разделители под заголовками, анимация раскрытия хедера на главной, и нумерация шагов процесса в виде открывающихся ламелей.

## О изображениях — важно

В проекте нет реальных фотографий объектов. Там, где по документации ожидались `.webp`-фото (hero-bg, фото жалюзи/штор/шкафов и т.д.), сейчас стоят **фирменные градиентные заглушки** (`ph-media` в main.css) с тонким ламельным узором — они держат цвета бренда и не выглядят как случайный стоковый фон, но это не готовые фото. Перед запуском сайта замените блоки с классами `ph-blinds`, `ph-roller`, `ph-wardrobe`, `ph-windows`, `ph-shutters`, `ph-hero` на реальные `<img>` с фотографиями объектов и продукции — это даст наибольший прирост доверия и конверсии.

Иконки (телефон, WhatsApp, Telegram, стрелки, галочки и т.д.) — инлайн SVG прямо в HTML, а не отдельные файлы: так их цвет наследуется от текста через `currentColor` и не нужно плодить светлую/тёмную версию каждой иконки.

## Форма заявки

Форма на `/contact/` сейчас работает только на фронтенде (Alpine.js) — при отправке показывает подтверждение, но никуда не отправляет данные. Сайт статический, бэкенда нет. Чтобы заявки реально приходили, подключите один из вариантов:
- сервис приёма форм (Formspree, Getform, Web3Forms) — просто меняете `action` формы;
- собственный бэкенд на Timeweb, как указано в разделе хостинга документации.

## Публикация

Статический вариант — GitHub Pages: залить содержимое этой папки в репозиторий и включить Pages для ветки. Все внутренние ссылки относительные, поэтому сайт будет работать и в корне домена, и в подпапке.
